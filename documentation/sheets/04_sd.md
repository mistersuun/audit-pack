# SetD - Sommaire Journalier des Depots (`SetD`)

**Excel Sheet:** `SetD` | **UI Tab:** SD | **Dimensions:** 36 x 139
**Template:** templates/audit/rj/tabs/sd.html
**Mapper:** utils/rj_mapper.py -> `SETD_MAPPING`, `SETD_PERSONNEL_COLUMNS`
**API:** POST /api/rj/fill/SetD

## 1. Purpose

SetD (Sommaire Journalier des Depots) tracks daily deposit settlements per personnel account for the month. Each row represents one calendar day (1-31) and each column represents a personnel or special account. The sheet aggregates daily RJ totals and individual settlement amounts, feeding back into the Recap sheet at Row 22 (Depot Canadien).

## 5. Macros & Operations

| Operation                  | Function                              | Description                                    |
|----------------------------|---------------------------------------|------------------------------------------------|
| Fill single cell           | `fill_setd_day(day, amount, col)`     | Write amount for a given day and account column|
| Sync from DueBack          | `sync_duback_to_setd()`              | Macro that pushes DueBack data into SetD        |

**sync_duback_to_setd():** Reads verified settlement data from the DueBack sheet and writes corresponding amounts into the correct day-row and personnel-column in SetD. This is the primary automated data entry path.

## 6. Data Flow

```
DueBack ──sync_duback_to_setd()──> SetD (personnel columns C-EI)
                                        │
Recap B23 ─────────────────────────> SetD column B (RJ daily total)
                                        │
SetD row 36 (monthly totals) ──────> Recap Row 22 (Depot Canadien)
```

- **Upstream:** DueBack sheet provides per-person settlement amounts. Recap B23 provides the RJ daily total.
- **Downstream:** Monthly totals (row 36) feed back to Recap Row 22 (Depot Canadien) via Excel formula.

## 8. Known Issues & Gotchas

- **Row 36 is FORMULA:** Never write data to row 36; it contains SUM formulas for monthly totals.
- **Column offset:** Personnel columns start at C (index 2), not A. The `account_col` parameter in `fill_setd_day()` expects the Excel column letter, not a zero-based index.
- **135 columns:** The sheet extends to column EI. Ensure Excel column-letter utilities handle multi-character columns correctly.
- **Sync direction:** Data flows from DueBack to SetD, not the reverse. Manual edits in SetD will not propagate back to DueBack.
- **Day validation:** Days 29-31 may not exist for all months. The filler should validate against the actual month length before writing.
