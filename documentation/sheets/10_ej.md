# EJ - Etat Journalier ([ej])

**Excel Sheet:** `ej` | **Dimensions:** 233 rows x 8 cols
**Parsed by:** `rj_sheet_parser.py` -> `parse_ej_sheet()`
**Database model:** `JournalEntry`

## 1. Purpose

The EJ (Etat Journalier) sheet contains GL (General Ledger) journal entries for the reporting period. Each row represents a single journal entry line with its GL account code, cost center allocation, description, source reference, and monetary amount. With 233 rows, this is one of the denser sheets in the RJ workbook and serves as the primary bridge between the hotel's daily operational data and the general ledger.

## 2. Sheet Layout

- **Rows 1-233:** One journal entry per row, no header row in the traditional sense (column labels are implicit).
- **Columns A-G:** Seven data columns plus one implied index column.
- The `source` column (F) references the originating sub-journal (e.g., `s-ej10`), linking each entry back to its transaction batch.
- Amounts in column G are signed: positive for revenue/credits, negative for expenses/debits.

## 3. Column Reference

| Col | Header         | Type    | Description                                      |
|-----|----------------|---------|--------------------------------------------------|
| A   | code gl        | String  | GL account code (e.g., `075001`)                 |
| B   | cc1            | String  | Cost center level 1 (e.g., `2`)                  |
| C   | cc2            | String  | Cost center level 2 (`.` when not applicable)    |
| D   | description 1  | String  | Primary GL account description                   |
| E   | description 2  | String  | Secondary reference or sub-description            |
| F   | source         | String  | Source sub-journal identifier (e.g., `s-ej10`)   |
| G   | MONTANT        | Float   | Journal entry amount (signed)                    |

## 4. Sample Data

```
code gl  | cc1 | cc2 | description 1    | description 2 | source | MONTANT
---------|-----|-----|------------------|---------------|--------|----------
075001   | 2   | .   | VENTES CHAMBRES  | 46014         | s-ej10 | 901999.87
```

- `075001` is the GL code for room revenue.
- Cost center `2` with no sub-center (`.`).
- Source `s-ej10` indicates the 10th sub-journal batch.
- Amount `901,999.87` represents the total room sales posted.

## 5. Data Flow

```
Excel RJ workbook (ej sheet)
  -> rj_sheet_parser.py :: parse_ej_sheet()
    -> JournalEntry model (database)
      -> GL-level financial tracking
      -> Cross-reference with Recap and budget sheets
```

- The parser reads all 233 rows, maps each to a `JournalEntry` record keyed by GL code + cost centers.
- Journal entries feed into variance analysis when compared against the Budget sheet's expected GL distributions.
- The `source` field allows tracing entries back to their originating transaction batches for audit purposes.

## 6. Integration Status

| System      | Status                                                        |
|-------------|---------------------------------------------------------------|
| Web app     | Parsed and stored via `JournalEntry` model                    |
| CRM         | Not directly integrated; GL codes could map to guest segments |
| Analytics   | Available for GL-level trend analysis and anomaly detection    |

## 7. Analytics Potential

- **GL trend analysis:** Track month-over-month movement per GL account to detect anomalies or seasonal patterns.
- **Cost center profitability:** Aggregate amounts by cc1/cc2 to evaluate departmental financial performance.
- **Source journal audit:** Group entries by `source` to verify batch integrity and completeness.
- **Budget variance by GL:** Join with Budget sheet data on GL code to produce line-item variance reports.
- **Anomaly detection:** Flag entries with unusually large amounts or unexpected GL/cost-center combinations.
