#### INF-1-001: rj_native.py defines local auth decorator
- **File:** `routes/audit/rj_native.py` lines 36–43
- **Evidence:**
  ```python
  def auth_required(f):
      @wraps(f)
      def decorated(*args, **kwargs):
          if not session.get('authenticated'):
              from flask import redirect, url_for
              return redirect(url_for('auth_v2.login'))
          return f(*args, **kwargs)
      return decorated
  ```
- **Issue:** The local `auth_required` only checks `session.get('authenticated')` and redirects all failures to login — it does NOT return a 401 JSON response for API routes (paths starting with `/api/`), unlike the canonical `login_required` in `utils.auth_decorators`. This inconsistency means unauthenticated API calls to native RJ endpoints (e.g. `/api/rj/native/new`) return an HTML redirect instead of JSON `{'error': 'Non authentifié'}`.
- **Severity:** MEDIUM — functional difference in API auth response behavior; all routes ARE protected
- **Suggested fix:** Replace `@auth_required` with `@login_required` imported from `utils.auth_decorators`
